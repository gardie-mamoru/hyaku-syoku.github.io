# 週次運用プロンプト

1週間分の投稿を、台帳から選定し、運用計画に落とすためのプロンプトです。
Claude Project に本Skillを入れ、Google Sheets台帳の内容（またはその要約）を貼り付けて使います。

---

## そのまま貼り付けるプロンプト

```
あなたは20代・第二新卒向け「高年収求人の読み解きメディア」の運用ディレクターです。
このメディアは求人紹介・斡旋ではなく「求人票の読み解き・キャリア解説」メディアです。
以下のルールに従い、今週の投稿計画を作ってください。

# 入力
- 台帳データ（求人候補の一覧。スコア・投稿候補・投稿ステータス列を含む）を下に貼り付ける。
- 先週の反応データ（あれば）：伸びた投稿・保存された投稿・LINE登録が増えた投稿など。

# タスク
1. 台帳から「投稿候補（◎○）」かつ「投稿ステータスが未／選定済」の求人を対象にする。
2. 今週投稿する求人を 5〜7件 選定する。
   - スコア上位を基本にしつつ、職種・年収帯・働き方が偏らないように分散させる。
   - 出典確認日が古すぎるもの（鮮度不安）は除外し、備考に「要再確認」と記す。
3. 投稿順を決める（曜日割り当て）。
   - 週の前半に「保存されやすい解説系（◎）」、後半に「共感・軽め」を配置するなど、
     エンゲージが続く並びにする。
4. 各求人について、使う媒体を割り当てる：
   - X（単発 or スレッド）
   - Instagram（5枚 or 7枚カルーセル）
   - LINE配信（週1〜2回のまとめ配信に含めるか）
5. 週次の運用計画表を作る。
6. 先週の反応データがあれば、良かったパターンを今週にどう反映するか提案する。

# 絶対ルール
- 求人紹介・応募代行・面談調整を想起させる企画にしない。
- 断定・誇大表現を含む企画タイトルにしない。
- 各投稿は投稿前に legal-risk-checklist.md のチェックを通す前提で計画する。

# 出力

## A. 今週の選定（5〜7件）
表：|順番|曜日|職種|年収レンジ|スコア|媒体|狙い（なぜ今週これか）|

## B. 投稿カレンダー
月〜日の各日について、投稿する媒体と内容（求人名・フォーマット）を割り当てる。
LINE配信日も明記する。

## C. 媒体別の運用計画
- X：本数、単発/スレッドの内訳、投稿時間帯の目安
- Instagram：カルーセル本数、Canva作成が必要な枚数
- LINE：配信回数、まとめる内容、誘導の狙い

## D. 先週の学びの反映（反応データがある場合）
- 伸びた投稿パターン（切り口・フォーマット・時間帯）を3つ挙げる。
- それを今週の計画にどう反映したかを明記する。
- 逆に伸びなかったパターンは、今週は減らす/やめる提案をする。

## E. 次週への申し送り
- 今週やってみて検証したい仮説（1〜2個）。
- 台帳に追加すべき求人ジャンル（不足している年収帯・職種）。
```

---

## 運用のリズム（目安）

| タイミング | やること |
| --- | --- |
| 週の初め | このプロンプトで今週の5〜7件と投稿順を確定 |
| 平日 | Xを毎日、Instagramを週2〜3本、`job-analysis-to-post.md` で原稿生成 |
| 投稿直前 | `legal-risk-checklist.md` のチェックを毎回通す |
| 週1〜2回 | LINEでまとめ配信（読み解きの視点を配信） |
| 週末 | 反応データを記録し、次週プロンプトの「先週の反応データ」に渡す |

## 反応データとして記録するもの

- 投稿ごとの：インプレッション／保存数／リンククリック／LINE登録増加。
- どの「切り口」（年収の内訳・注意点・職種解説・職経アドバイス）が伸びたか。
- どの時間帯・曜日・フォーマットが伸びたか。

> これらを毎週 D「先週の学びの反映」に渡すことで、投稿パターンを継続的に改善します。

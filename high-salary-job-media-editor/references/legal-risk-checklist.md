# 法務・規約リスク チェックリスト

このメディアは**求人紹介・職業紹介事業ではない**という前提を守るためのチェックリストです。
求人探索・投稿生成・投稿前の各段階で、必ず確認してください。
（本チェックリストは一般的な運用上の注意であり、法的助言ではありません。判断に迷う案件は
専門家に相談してください。）

## A. 著作権・転載リスク

- [ ] **求人票の本文をそのままコピー・転載していない。**
      （見出し・キャッチコピー・箇条書きの丸写しも含む。必ず自分の言葉で要約する。）
- [ ] 投稿・台帳に保存するのは**短い要約と独自分析だけ**にしている。
- [ ] **企業ロゴ・企業が権利を持つ画像・写真を使っていない。**
- [ ] 図表・スクリーンショットを転載していない。

## B. 出典・エビデンス

- [ ] **出典URLを記録している。**（求人が載っている公開ページのURL）
- [ ] **確認日（出典確認日）を記録している。**
- [ ] 年収・条件は出典に基づく。憶測の数字を「事実」として書いていない。
- [ ] 「最新」「◯月時点」などの表記は、確認日と一致している。

## C. 公開情報のみを扱う

- [ ] **ログイン・会員登録が必要な求人を扱っていない。**
- [ ] 有料会員限定・非公開求人を扱っていない。
- [ ] 閲覧に規約違反となるスクレイピング等をしていない（人が読む範囲の公開情報のみ）。

## D. 職業紹介に見えないようにする（最重要）

このメディアは職業紹介事業（有料・無料を問わず、求職者と求人者の間をあっせんする行為）
には該当しないよう運用します。次を**しない**こと。

- [ ] 特定の求人への**応募を推薦・勧誘していない。**
- [ ] 企業への**推薦・紹介をしていない。**
- [ ] **応募代行をしていない。**
- [ ] 企業と求職者の**面談・面接の日程調整をしていない。**
- [ ] 「紹介します」「つなぎます」「推薦します」「あっせんします」等の表現を使っていない。
- [ ] 応募は**必ず読者自身が公式ページで行う**立て付けになっている。
- [ ] 投稿の主語が「読み解き・解説」であって「紹介・斡旋」になっていない。

## E. 個人情報

- [ ] **求職者（読者）の情報を、本人の同意なく第三者に提供していない。**
- [ ] LINE等で得た読者情報を、企業や外部に渡していない。
- [ ] 求人票に含まれる個人名・連絡先などの個人情報を掲載していない。

## F. 誇大表現・景表法的リスク

- [ ] **誇大表現・断定表現を使っていない。**
      （「必ず」「絶対」「誰でも」「確実に稼げる」など）
- [ ] 年収は**レンジと条件**で示している。上限だけを強調していない。
- [ ] インセンティブ・歩合・みなし残業込みの金額は、その旨を明記している。
- [ ] 他社・現職を貶める比較で煽っていない。

## G. 投稿前の最終確認（毎回）

投稿を公開する直前に、次をすべて確認してください。

- [ ] 求人票本文の転載がゼロ（要約と独自分析のみ）。
- [ ] 出典URL・確認日が台帳にある。
- [ ] ログイン不要の公開求人である。
- [ ] 「紹介・推薦・応募代行・面談調整」を想起させる表現がない。
- [ ] 断定・誇大表現がない。ポジティブ面と注意点が併記されている。
- [ ] 企業ロゴ・企業画像を使っていない。
- [ ] 「応募・詳細は公式の募集要項で確認を」という注記がある。
- [ ] 読者に不利益・誤解を与える表現がない。

> 1つでも [ ] が埋まらない場合は、**投稿しない**。修正してから再チェックする。

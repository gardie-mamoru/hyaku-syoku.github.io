# Google Sheets 求人台帳 スキーマ

求人候補を管理する台帳の列定義です。1求人＝1行。
**求人票の本文はそのまま保存しません。** 各セルには「短い要約」と「独自分析」だけを入れます。

## 保存ルール（最重要）

- **求人票本文をコピペしない。** どの列も、原文の丸写しではなく**自分の言葉での要約・分析**にする。
- 「注目ポイント」「注意点」「向いている人」などは、求人票から**読み解いた独自の見解**を書く。
- 年収・条件は出典に基づく。**出典URLと出典確認日を必ず埋める。**
- 空欄のまま投稿判定しない。特に「出典URL」「出典確認日」「スコア」は必須。

## 列定義

| # | 列名 | 型/例 | 入力ルール |
| ---: | --- | --- | --- |
| 1 | 取得日 | 日付（2026-07-01） | 情報を取得した日 |
| 2 | 出典URL | URL | 公開求人ページのURL。**必須**。ログイン要のURLは不可 |
| 3 | 取得元 | テキスト（求人サイト名/媒体名） | どこで見つけたか |
| 4 | 企業名 | テキスト | 分かる範囲で。伏せる場合は「（社名非公開）」 |
| 5 | 職種 | テキスト | 例：法人営業／Webエンジニア |
| 6 | 年収レンジ | テキスト（例：400〜650万円） | **下限〜上限**で。条件込みなら注記 |
| 7 | 勤務地 | テキスト | 例：東京（リモート可） |
| 8 | 働き方 | テキスト | リモート/出社/フレックス/残業目安など |
| 9 | 雇用形態 | テキスト | 正社員/契約/業務委託 など |
| 10 | 若手向け要素 | テキスト（要約） | 第二新卒歓迎/未経験可/若手活躍 などの読み解き |
| 11 | 注目ポイント | テキスト（独自分析） | 読み解いた魅力。転載しない |
| 12 | 注意点 | テキスト（独自分析） | みなし残業/歩合/上限条件などの注意 |
| 13 | 向いている人 | テキスト（独自分析） | どんな20代に向くか |
| 14 | 職務経歴書で強調すべきこと | テキスト（独自分析） | 応募時に見せると強いポイント |
| 15 | スコア | 数値（0〜100） | `job-scoring-rubric.md` で算出 |
| 16 | 投稿候補 | 記号（◎/○/△/×） | 80+◎ / 70-79○ / 60-69△ / 59-× |
| 17 | 投稿ステータス | 選択肢 | 未／選定済／作成中／投稿済／見送り |
| 18 | 出典確認日 | 日付 | 出典URLを最後に確認した日。**必須** |
| 19 | 備考 | テキスト | 補足・再確認事項など |

## 列16「投稿候補」の記号対応

| スコア | 記号 | 意味 |
| ---: | :---: | --- |
| 80〜100 | ◎ | 優先投稿候補 |
| 70〜79 | ○ | 投稿候補 |
| 60〜69 | △ | 保留 |
| 59以下 | × | 投稿しない |

## 列17「投稿ステータス」の遷移例

```
未 → 選定済（週次で選出）→ 作成中（原稿生成）→ 投稿済
                                     └→ 見送り（リスク/鮮度で取りやめ）
```

# 投稿テンプレート集

すべて**求人票の読み解き**として書きます。転載・断定・煽り・紹介斡旋はしません。
`{ }` の部分を差し替えて使ってください。
どのテンプレートも、末尾に**出典・確認日・「詳細は公式で確認を」の注記**を入れます。

---

## 1. X 単発投稿（〜140字目安）

```
【20代で年収{下限}〜{上限}万円の求人を読み解く】

{職種}／{勤務地}／{働き方}

読み解きポイント：
・{注目ポイントを1つ、短く}
・注意点：{注意点を1つ}

向いてるのは{向いている人}な人。

※出典：公開求人（{確認日}確認）。応募・詳細は公式の募集要項で。
```

**ルール**：金額は必ずレンジ。上限だけの見出しにしない。注意点を必ず1つ入れる。

---

## 2. X スレッド（3〜5ツイート）

```
1/ 【求人票の読み解き】20代・第二新卒でも狙える年収{下限}〜{上限}万円の{職種}。
   でも数字だけ見て飛びつくと危ない。どこを見るべきか順番に解説👇

2/ ①どんな仕事か
   {職種の内容を1〜2行で要約（転載しない）}。{市場価値の一言}。

3/ ②なぜこの年収レンジなのか
   {年収の背景・条件を読み解く}。{インセンティブ/みなし残業などの注意があれば明記}。

4/ ③向いている人・注意点
   向いてる：{向いている人}
   注意：{注意点}

5/ ④職務経歴書で強調するなら
   {強調ポイント}を書けると通りやすい。

   ※出典：公開求人（{確認日}確認）。応募・詳細は必ず公式の募集要項で確認を。
```

## 3. Instagram 5枚カルーセル原稿

```
[1枚目・表紙]
20代で年収{下限}〜{上限}万円？
「{職種}」の求人票を読み解く

[2枚目・どんな仕事]
・職種：{職種}
・勤務地：{勤務地}／働き方：{働き方}
・{仕事内容を1〜2行で要約}

[3枚目・ここが魅力]
✔ {注目ポイント①}
✔ {注目ポイント②}
（年収は条件込み。上限は{上限条件}が前提）

[4枚目・でも注意]
⚠ {注意点①}
⚠ {注意点②}
数字だけで判断しないのが大事。

[5枚目・まとめ＆導線]
向いてる人：{向いている人}
職務経歴書では「{強調ポイント}」を書けると強い。

▶ 求人の読み解き方をLINEでも配信中（プロフィールから）
※出典：公開求人（{確認日}確認）。応募・詳細は公式の募集要項で。
```

## 5. LINE 誘導文

投稿の最後、またはプロフィール導線に使う短文。**「紹介」ではなく「読み解きの配信」**として書く。

```
（パターンA・投稿末尾用）
求人票の"読み解き方"を、LINEでも配信しています。
20代・第二新卒が年収を上げるときに見るべきポイントを、求人票ベースで解説。
▶ プロフィールのリンクから登録できます。
※求人紹介・斡旋は行いません。応募は各自で公式ページから。

（パターンB・登録直後の挨拶）
登録ありがとうございます！
このLINEでは「高年収求人の"読み解き方"」を配信します。
・求人票のどこを見れば地雷を避けられるか
・20代でも狙える職種
・職務経歴書での見せ方
を、公開求人を教材に解説していきます。
※特定企業への紹介・応募代行はしません。応募は必ず公式の募集要項から。
```

## 6. 投稿前チェックリスト（テンプレ運用版）

投稿を出す直前に、毎回このチェックを通す（詳細は `legal-risk-checklist.md`）。

- [ ] 求人票の本文を転載していない（要約・独自分析のみ）
- [ ] 年収はレンジ＋条件で書いた（上限だけの煽りなし）
- [ ] 注意点を1つ以上入れた（ポジ面と併記）
- [ ] 「紹介・推薦・応募代行・面談調整」を想起させる表現がない
- [ ] 断定・誇大表現（必ず／絶対／誰でも／確実に稼げる）がない
- [ ] 企業ロゴ・企業画像を使っていない
- [ ] 出典URL・確認日が台帳にある
- [ ] 「応募・詳細は公式の募集要項で確認を」の注記を入れた
- [ ] LINE導線は「読み解きの配信」立て付けになっている

> 1つでも埋まらなければ**投稿しない**。修正して再チェック。

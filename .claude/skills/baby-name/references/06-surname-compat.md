# 名字（姓）との相性ロジック

姓は固定。**姓の画数に合わせて、五格がすべて吉になる名前の画数を逆算**するのが効率的。
さらに音・字面・バランスの相性も見る。

---

## 1. 画数による逆算アルゴリズム

### 前提
- 姓の各字の画数を確定（旧字体ルール、`02-kakusu-gokaku.md`）。例：姓が2字で `s1, s2`。
- 名を2字 `n1, n2` とする（一字名なら霊数処理）。

### 計算される五格
- 天格 = s1 + s2 （**固定**・姓で決まる）
- 人格 = s2 + n1
- 地格 = n1 + n2
- 外格 = s1 + n2 （＋一字姓/一字名なら霊数）
- 総格 = s1 + s2 + n1 + n2

### 逆算手順
1. 天格を計算（固定）。
2. **人格を吉にする n1 の候補**を列挙：`人格 = s2 + n1` が `03-strokes-81.md` で吉/大吉になる n1 を全部出す。
3. その各 n1 に対し、**地格・外格・総格も吉**になる n2 を探す：
   - 地格 = n1 + n2 が吉
   - 外格 = s1 + n2 が吉
   - 総格 = s1+s2+n1+n2 が吉
4. **4格すべて（人格・地格・外格・総格）が吉**になる (n1, n2) の組を「画数的に最良の名前画数」として確保。
5. 完璧な組が無ければ、**人格と総格を最優先**で吉にし、残りは半吉以上で妥協。
6. 確保した画数組合せに対し、**その画数を持つ実在の漢字**で、思い・読み・五行に合うものを当てはめる。

> 💡 実務：n1 候補は1〜20画程度、n2 も同様の現実的範囲に絞って総当たりすれば、人手でも十分計算可能。**計算過程（どの組が何格で吉か）を表で残す**こと。

### 計算例（姓「佐藤」＝佐7・藤18 と仮定）
- 天格 = 7 + 18 = 25（吉）✓ 固定
- 人格 = 18 + n1。n1=3なら21（大吉）、n1=5なら23（大吉）… → 良い n1 を選ぶ。
- n1=5（人格23・大吉）とすると、地格=5+n2、外格=7+n2、総格=25+5+n2=30+n2。
  - n2=6：地格11(大吉)/外格13(大吉)/総格36(凶) → 総格×
  - n2=8：地格13(大吉)/外格15(大吉)/総格38(半吉) → △
  - n2=16：地格21(大吉)/外格23(大吉)/総格46(凶) → ×
  - n2=11：地格16(大吉)/外格18(吉)/総格41(大吉) → **全吉！◎**
  - → 「名 = 5画 + 11画」が画数的に最良の一例。あとは5画＆11画で良い漢字を探す。

## 2. 音（響き）の相性

姓と名を続けて読んだときの語感を確認する。

- **モーラ（拍）のバランス**：姓3拍＋名2拍など、リズムが良いか。姓が短い（1〜2拍）なら名は少し長め、姓が長いなら名は短めが据わりやすい（絶対ではない）。
- **母音の流れ**：同じ母音が連続しすぎないか（例：姓「あおやま」＋名「ななこ」など a の連続は好み次第）。
- **頭文字の重複**：姓の頭と名の頭が同子音だと言いにくい場合がある（例：「さ」さ…）。語呂で確認。
- **濁音・破裂音の重さ**：濁点が多いと重い印象。柔らかくしたいなら清音多めに。
- **姓＋名で別の語や不都合な音にならないか**（必ずチェック）。

## 3. 字面（見た目）の相性

- **画数バランス**：姓が画数多め（重厚）なら、名も極端に少ないとアンバランス。視覚的な重心を見る。
- **同じ部首の重複**：姓と名で同じ部首が並ぶとくどい場合がある（例：姓「林」＋名に「森」など木が過剰）。逆に狙って統一感を出すのもあり。
- **漢字の難易度**：姓が難読なら名は読みやすく、等の社会的配慮。
- **縦書き（戸籍・署名）での見栄え**も意識。

## 4. 統一感（きょうだいがいる場合）

第一子の名前と揃える観点（`01-hearing.md` Q7）：
- **止め字を揃える**（例：兄「〜翔」、弟「〜翔」/ 姉「〜花」、妹「〜菜」）。
- **テーマを揃える**（自然・季節・宝石・音楽 など）。
- **読みの音数・トーンを揃える**。
- **画数の吉は各自で独立に確保**（兄に揃えて画数が凶になっては本末転倒）。

---

## 5. 総合相性スコアの考え方

姓との相性は、以下を総合：
1. **画数**：五格が吉で揃うか（最重要・逆算で担保）。
2. **五行**：姓の五行と名の五行が相生/比和で流れるか（`05`）。
3. **音**：続けて読んで心地よいか、不都合がないか。
4. **字面**：視覚バランス・難易度・部首。
5. **統一感**：きょうだいとの調和（該当時）。

各観点を ◎○△ で評価し、`07-proposal-format.md` の表で提示する。

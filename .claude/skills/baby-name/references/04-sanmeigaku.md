# 算命学（さんめいがく）— 生年月日から見る命式の基礎

生年月日（または出産予定日）が分かる場合、算命学の観点を加える。
**陰陽五行**と**十干十二支**を使い、その子が生まれ持つ「気の偏り」を読み、名前で補完する。

> 注意：算命学の完全な命式（十大主星・十二大従星など）は専門的で計算が複雑。
> 本スキルでは**実用的な範囲**＝「生まれ年・月・日の五行バランス」と「干支」を見て、
> **不足する五行を名前の漢字（部首・意味）で補う**方針を取る。これだけでも十分ロジカル。

## 3. 生年の干支の出し方（簡易）

- **年の十干**：西暦の下1桁で決まる。
  - 4→甲, 5→乙, 6→丙, 7→丁, 8→戊, 9→己, 0→庚, 1→辛, 2→壬, 3→癸
  - 例：2026年 → 下1桁6 → 丙
- **年の十二支**：西暦 ÷ 12 の余りで決まる。
  - 余り 4→子,5→丑,6→寅,7→卯,8→辰,9→巳,10→午,11→未,0→申,1→酉,2→戌,3→亥
  - 例：2026 ÷ 12 = 168余り10 → 午
  - → **2026年は「丙午（ひのえうま）」**。五行は 火＋火 で **火が非常に強い年**。

> 月・日の干支は六十干支の暦（万年暦）が必要。**月・日まで厳密に出す場合は、生年月日を確定したうえで万年暦データを参照する**。年だけでも大まかな五行傾向は掴める。生年月日が確定したら、可能な範囲で月・日も算出して精度を上げる。

## 4. 命名への応用（核心）

### 4-1. 五行バランスを見る
生まれ持つ干支の五行を数え、**多すぎる五行／不足する五行**を把握する。
例：2026年丙午生まれ＝火が過剰 → **火を強めすぎない**、むしろ**水（鎮める）や木（巡らせる）の要素を名前に足す**とバランスが整う、という読み方をする。

### 4-2. 五行を名前で補う方法
漢字の**部首・意味・成り立ち**で五行を持たせる（`05-gogyo-aishou.md` に対応表）。
- 木が欲しい → 木偏・草冠・林・森・葉・芽 等
- 火が欲しい → 火偏・日・陽・明・晴・灯 等
- 土が欲しい → 土偏・山・岩・地・基・城 等
- 金が欲しい → 金偏・宝石名・鋼・鈴・錬 等
- 水が欲しい → 氵・雨・川・海・氷・潤 等

### 4-3. 注意
- 五行補完は「不足を補い、過剰を避ける」のが基本だが、**親の思いを上書きしない**。
  五行的に水が欲しくても、親が「陽」の字に強い思い入れがあるなら、その思いを尊重して別の格で調整する。
- 算命学はあくまで**補助的観点**。画数・思い・響きと矛盾したら総合判断する。
- 「火が強い年だから火の字は絶対NG」のような断定はしない。「バランス上、こう補うと整います」という提案の形にする。

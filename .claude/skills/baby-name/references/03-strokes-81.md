## 補足：特定数の扱い

### 女性に強すぎると言われる数（旧来説）
21, 23, 33, 39 などは「女性が持つと運勢が強すぎて家庭運に影響」とする**古い説**がある。
→ **現代では根拠が薄く、価値観も変化**しているため、機械的に避ける必要はない。
依頼者がこの説を気にするか確認し、気にしないなら通常の大吉として扱ってよい。気にする場合のみ代替を用意する。

### 「孤独運」「波乱運」などの特殊運
特定の数（例：人格や地格が 9,10,19,20,26,28,34 等）は孤独・波乱の象意を持つとされる。
→ 一つの格が凶でも、**他の格が補えば総合的に良い**ことが多い。一格の凶だけで全否定しない。

### 判定の総合ルール
- **人格・総格が吉**であることを最優先で確保する。
- 地格・外格も吉が望ましいが、すべてを大吉で揃えるのは現実的に難しい。
- 「**凶の格が無い、または最重要格が吉**」を合格ラインの目安とする。
- 提示時は各格の数・吉凶・象意を表で見せ、総合コメントを付す。
